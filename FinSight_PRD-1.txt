FINSIGHT — DATA ANALYTICS & PERSONAL FINANCE APP
Product Requirements Document (PRD)

1. PROJECT OVERVIEW
FinSight is a data analytics-based personal finance application that helps users record income and expenses, understand spending patterns, monitor budgets and savings, and receive data-driven financial insights.

The main purpose of the project is to demonstrate how raw financial data can be collected, processed, analyzed, visualized, and converted into useful insights through a user-friendly application.

2. PROJECT OBJECTIVES
• Track personal income and expenses.
• Categorize transactions for meaningful analysis.
• Provide interactive dashboards and visualizations.
• Identify spending trends and high-spending categories.
• Compare actual spending with planned budgets.
• Analyze savings behavior.
• Detect unusual spending patterns.
• Generate data-driven insights and reports.
• Demonstrate practical use of data analytics in a real-world application.

3. TARGET USERS
• College students
• Young professionals
• Individuals who want to understand their personal spending
• Users who want a simple way to monitor budgets and savings

4. CORE FEATURES

4.1 User Authentication
• User registration and login.
• Secure user session.
• Logout functionality.

4.2 Dashboard
The dashboard provides a quick financial overview:
• Total income
• Total expenses
• Total savings
• Current budget status
• Recent transactions
• Spending summary
• Key financial insights

4.3 Income & Expense Tracking
Users can:
• Add income transactions.
• Add expense transactions.
• Select a category.
• Enter amount, date and description.
• Edit or delete transactions.
• View transaction history.

4.4 Expense Categories
Example categories:
• Food
• Shopping
• Transport
• Education
• Entertainment
• Bills
• Healthcare
• Travel
• Other

4.5 Data Analytics
FinSight analyzes transaction data to provide:
• Category-wise spending analysis
• Monthly and weekly spending trends
• Income vs expense comparison
• Savings trend
• Highest spending categories
• Average spending
• Budget utilization
• Spending pattern analysis

4.6 Data Visualization
The application should use charts such as:
• Pie/donut chart for expense distribution
• Bar chart for category comparison
• Line chart for monthly spending trends
• Income vs expense chart
• Savings trend chart
• Budget vs actual spending chart

4.7 Budget Management
Users can:
• Set monthly budgets.
• Set category-wise budgets.
• Track budget usage.
• View remaining budget.
• Receive an alert/indicator when spending approaches or exceeds a budget.

4.8 Savings Analysis
The application calculates:
• Total savings
• Monthly savings
• Savings rate
• Savings trend
• Income-to-expense relationship

4.9 Unusual Spending Detection
The analytics module can identify transactions or periods that differ significantly from a user's normal spending pattern.

Examples:
• An unusually high expense.
• A category suddenly increasing compared with previous periods.
• Spending that exceeds a normal historical range.

4.10 Smart Insights
Based on analyzed data, FinSight can generate simple insights such as:
• Which category has the highest spending.
• Whether expenses increased or decreased.
• Whether the user is within the planned budget.
• Which month had the highest expenses.
• How savings changed over time.

4.11 Reports
Users can view or generate a financial summary containing:
• Income
• Expenses
• Savings
• Category breakdown
• Budget performance
• Trends
• Key insights
